TIP KEAMANAN HARI INI

OTP adalah rahasia, bukan untuk dibagikan.

Bank, marketplace, dan layanan resmi tidak akan meminta kode OTP atau PIN melalui chat atau telepon.

ⓘ Dashboard ini berjalan dalam mode demo lokal. Angka dan hasil pemeriksaan berasal dari aktivitas pada browser ini, bukan pemantauan keamanan server secara real-time.

ALAT PEMERIKSAAN

Deteksi Pesan Scam

Tempel pesan yang kamu terima untuk mengenali pola penipuan, tekanan psikologis, dan permintaan data sensitif.

▤
01

Masukkan isi pesan

Jangan sertakan OTP, PIN, kata sandi, atau data pribadi yang masih aktif.

Hindari memasukkan data rahasia.0 / 5000
APA YANG DIPERIKSA?

Kenali tanda-tanda pesan berbahaya

  • ✓ Hadiah atau undian yang tidak diikuti
  • ✓ Permintaan OTP, PIN, atau password
  • ✓ Desakan transfer uang segera
  • ✓ Ancaman akun diblokir atau ditutup
  • ✓ Tautan dan identitas pengirim mencurigakan
♧

Analisis demo dilakukan di browser. Teks tidak dikirim ke server oleh aplikasi ini.
